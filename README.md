# 🍔 LancheHub

Sistema de gerenciamento para lanchonetes, desenvolvido com foco em organização de pedidos, mesas, produtos e demais operações do estabelecimento.

> ⚠️ **Status: Em desenvolvimento**

O **LancheHub** ainda está em fase inicial de desenvolvimento. Neste momento, a estrutura do projeto está sendo construída gradualmente.

## 📌 Progresso atual

Até o momento, foram implementados apenas os **Repositories** das entidades do sistema.

* [x] Estrutura inicial do projeto
* [x] Repositories
* [ ] Services
* [ ] DTOs
* [ ] Controllers / Endpoints
* [ ] Front-end
* [ ] Autenticação e autorização
* [ ] Integração entre Front-end e Back-end
* [ ] Testes
* [ ] Funcionalidades adicionais

## 🛠️ Tecnologias

As tecnologias utilizadas no projeto incluem:

* **Java**
* **Spring Boot**
* **Spring Data JPA**
* **PostgreSQL**
* **Vue.js** *(front-end)*

## 🚧 Desenvolvimento

O projeto será desenvolvido por etapas, começando pela implementação da camada de persistência e posteriormente avançando para as demais camadas da aplicação.

Novas funcionalidades serão adicionadas conforme o desenvolvimento do sistema avançar.
